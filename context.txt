2. CORE MOBILE APPLICATION FEATURES & MODULES (13 MODULES)
========================================================================

The website showcases the actual capabilities of the Focus Android App,
detailing these specific native software architectures:

*   2.1 DYNAMIC QUOTES ENGINE (HOME SCREEN)
    - Delivers high-fidelity curated quotes in a stunning calligraphy format.
    - Utilizes a unique, handcrafted calligraphy typeface (Google Font "Playwrite GB S") 
      exclusively for the core quote displays.
    - Allows swift sliding, sharing, and copying of quotes with a single tap.
    - Provides a functional "Refresh" trigger to fetch a new random piece of wisdom from 
      the localized catalog instantly.

*   2.2 CATEGORIZED EXPLORE HUB
    - Dive into tailored mental categories matching your current mood: 
      Motivation, Calm, Focus, Hard Work, Love, Success, and more.
    - Features a responsive wrapping grid system optimized to display perfectly across 
      standard smartphones, tablet layouts, and foldable devices without cutoffs.

*   2.3 ADVANCED SEARCH & FILTERING
    - Search through thousands of stored offline quotes by key terms, concepts, authors, or categories.
    - Auto-Suggestions: Displays unique recommendations under a "Suggested for You ✦" header on initial load.
    - Session-Based Filtering: Filters suggested quotes using session history to prevent suggestions from repeating.
    - Dynamic Category Chips: Scans the entire localized JSON quote database at runtime to extract unique tags, 
      normalize them, sort them alphabetically, and display them as interactive filter chips.

*   2.4 OFFLINE FAVORITES VAULT
    - Bookmark the quotes that speak directly to your soul.
    - Keep them locally cataloged for permanent, fast offline reflection without an internet connection.
    - Streamlined UI with direct action icons and batch multi-select capabilities.

*   2.5 DAILY MOOD TRACKING (ENFORCED SINGLE-LOG)
    - Keep a pristine log of your emotional states over the months.
    - Enforces a secure "once per day" logging policy: overwrites previous choices if logged again on the same day.
    - Guarantees monthly analytics, averages, and charts remain 100% accurate and never skewed by double-logs.

*   2.6 REFLECTIVE JOURNAL (PUBLIC & PRIVATE)
    - An elegant personal diary system integrated directly inside the app.
    - Write daily reflections, goals, or notes with premium, book-grade typography using "Literata".
    - Supports standard Public Journaling and PIN-secured Zen Journal (Private Journaling).

*   2.7 GAMIFIED BADGE & MILESTONE SYSTEM (ACHIEVEMENTS)
    - Earn and unlock customized aesthetic achievement badges for your consistency (11 unlockable milestones).
    - Gamifies your growth journey, encouraging daily check-ins without predatory dopamine hooks.

*   2.8 SELF-DISCIPLINES STREAK TRACKER
    - Track consecutive days of logging into your journey.
    - Displays a highly motivating streak celebration dashboard to keep your habits consistent.

*   2.9 ZEN JOURNAL SECURE PIN PROTECTION
    - Secure lock capability using custom-built, local PIN setup and unlock screens.
    - Secure cryptographic validation using standard SHA-256 hashing without saving plain text passwords to disk.
    - System-level window security masking (`WindowManager.LayoutParams.FLAG_SECURE`) to block screenshots and hide preview details in the app switcher.

*   2.10 DOUBLE-TAP MULTI-SELECT SYSTEM
    - Batch selection mode triggered by double-tapping any quote on Home, Favorites, History, Search, and Explore screens.
    - Smooth scaling (contracts selected items to `0.97f` scale) and orange highlighting accents (`0xFFFC6E20` at 8% alpha overlay).
    - Contextual Top App Bar enabling batch operations: Add to Favorites, Share, Copy, or Delete (with verification dialog and undo snackbar support).

*   2.11 MINDFULNESS ANALYTICS & WEEKLY REPORT CARD
    - Bezier Mood Curve: Custom Canvas-drawn weekly mood Bezier curve displaying mood levels accompanied by emoji node points.
      Uses fallback logic rendering neutral 3.0f score (😐) for days with journal entries but no logged mood.
    - Weekly Highlights Dashboard: Displays current streak, combined journal entries, and average mood label/emoji.
    - Public Journal Word Cloud: Visual tag cloud of top words used in the public journal, excluding private entries.
    - Partial Week Banner: Warns user with subtle card if week is incomplete.
    - Visual Export & Sharing: Generates high-resolution bitmap screenshot of report card and launches system share sheet.

*   2.12 FOCUS GUARD SYSTEM (NEW MODULE)
    - Notification Silencer: Program quiet time windows to automatically enable Android's Do Not Disturb (DND) mode.
    - App Blocker: Select distracting third-party apps and schedule blocking windows via persistent `AppBlockerService` (`UsageStatsManager`).
    - Block Overlay: Intercepts opened distracting apps with `BlockOverlayActivity` featuring pulsing vector shield, motivational quotes, "Go Back to Focus" action, and temporary 5-minute override.
    - Status Notifications: System shade alerts when DND triggers or app is blocked with 5s cooldown throttling.
    - Focus Guard Home Card: Status-aware shortcut card on home screen.

*   2.13 DYNAMIC WALLPAPER GENERATOR (NEW MODULE)
    - Create bespoke, typography-focused wallpapers using quote texts and signatures.
    - Curated Background Presets: Choose from custom HSL color-based themes (Noir, etc.).
    - Typography Styles: Custom font selections (Literata, Inter, Lora).
    - Text Alignments: Left, Center, or Right alignments.
    - Auto/Manual Text Sizing: Dynamic text scaling or manual font size slider.
    - Film Grain Overlay: Adjustable opacity slider (0% to 8%).
    - Custom Signature & Branding Toggle: Custom author signature and watermark toggle.
    - Quick Deploy Actions: Set as Home Screen, Lock Screen, or both wallpapers, save to gallery, or share immediately.
